----------------
You will have to install the following to get the front-end implementation to run as planned
npm create vite@latest 
npm install
npm install react-router-dom //for routing to different pages
npm install @mui/material @emotion/react @emotion/styled //for tables and buttons
npm install @mui/icons-material //for UI icons like shopping cart icon
npm install express //for backend web server
npm install cors //to connect front-end to back-end
npm install sqlite3 //for access to the database
